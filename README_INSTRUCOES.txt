PASSO A PASSO PARA PUBLICAR SEU SITE GRATUITAMENTE NO STREAMLIT CLOUD

PASSO 1: CRIAR UMA CONTA NO GITHUB
1. Acesse o site do GitHub e crie uma conta gratuita.

PASSO 2: CRIAR O REPOSITÓRIO DO PROJETO
1. No GitHub, clique no botão + no canto superior e escolha New repository.
2. Nomeie o repositório como: meu-gerador-de-laudos
3. Mantenha marcado como Public e clique em Create repository.

PASSO 3: ENVIE OS ARQUIVOS
1. Na página do repositório, clique em Add file -> Upload files.
2. Descompacte este arquivo ZIP no seu dispositivo.
3. Envie os arquivos e pastas:
   - app.py
   - requirements.txt
   - packages.txt
   - pasta modelos/ (com o arquivo LAUTO AUTOMATICO rev4 - Copy.docx dentro)
4. Clique no botão Commit changes.

PASSO 4: PUBLICAR NO STREAMLIT CLOUD
1. Acesse o site do Streamlit Cloud (streamlit.io/cloud).
2. Faça login com sua conta do GitHub.
3. Clique em Create app e selecione seu repositório meu-gerador-de-laudos.
4. No campo Main file path, digite: app.py
5. Clique em Deploy!

Pronto! Em 1 a 2 minutos seu site estará no ar com link público oficial!
Você poderá acessar e usar do seu iPhone de qualquer lugar!
